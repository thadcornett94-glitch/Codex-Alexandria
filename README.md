## 🚀 Getting Started

### Prerequisites
- Node.js 14+
- npm or yarn
- MongoDB or compatible database
- Cloud storage account

### Installation

```bash
# Clone the repository
git clone https://github.com/thadcornett94-glitch/Codex-Alexandria.git
cd Codex-Alexandria

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Add database and storage credentials

# Build search indices
npm run build:search

# Start development server
npm run dev

# Access at http://localhost:3000
```
